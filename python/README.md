# artiik (Python)

Context management for AI agents: it keeps requests under budget, compacts with your provider's native features, keeps what must survive every compaction, remembers across sessions and shows what the model saw.

**Status: pre-alpha.** The package is being rewritten, and this release contains no features yet. Follow the [roadmap](https://github.com/Artiik-lab/artiik/issues/2).

- Zero required dependencies. Python 3.11+.
- The 0.1 API (`ContextManager`) was removed. It stays available at the [`v0.1.1` tag](https://github.com/Artiik-lab/artiik/tree/v0.1.1).

See the [project README](https://github.com/Artiik-lab/artiik#readme) for the plugin and the skill.
